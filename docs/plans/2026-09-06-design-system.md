# MenuLive: дизайн-система (из макета MenuLive.dc.html)

Источник: проект Claude Design `ef29e59d-690d-49c7-8524-f7857d469c7c`, файл `MenuLive.dc.html`.
Этот документ является нормативным для реализации интерфейса.

## Идея

Интерфейс это плёнка поверх живой камеры: тёмные непрозрачные плашки, полновесный белый текст,
свободный центр. Ни одного полупрозрачного текста. Любая плашка живёт на затемнении со стеклом,
поэтому читается на любом кадре.

## Шрифт

`Golos Text` (Google Fonts), запасные `'Helvetica Neue', Helvetica, sans-serif`.
Держит кириллицу и узбекскую латиницу. Подключение:
`https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600;700;800&display=swap`

## Токены

### Перекрашивается под бренд ресторана, ровно 5 значений

| Токен | Значение по умолчанию | Где применяется |
|---|---|---|
| `--ml-accent` | `#F2B24C` | главная кнопка, активный чип, активная вкладка |
| `--ml-accent-2` | `#46C6A8` | промо-бейдж, счётчик количества |
| `--ml-surface` | `#12100E` | база плашек, тон под бренд |
| `--ml-on-accent` | `#12100E` или `#FFFFFF` | текст на акценте, по контрасту |
| `--ml-logo` | SVG, высота 28 | монохромный белый |

### Не меняется никогда

| Токен | Значение |
|---|---|
| `--ml-scrim` | плотность 0.82 |
| `--ml-blur` | 20px |
| `--ml-text` | `#FFFFFF` |
| `--ml-text-2` | `#E5DED2` |
| `--ml-line` | `rgba(255,255,255,.12)` |
| `--ml-error` | `#F5665A` |
| `--ml-waiter-bg` | `#0B0A09` |

## Система размеров

- **Шаг 4 px.** Отступы 4 · 8 · 12 · 16 · 24 · 32.
- **Поля:** 16 px по краям экрана, 12 px внутри плашек.
- **Типографика:** 34/800 · 24/700 · 20/700 · 17/600 · 15/500 · 13/500 · 11/600 капс.
- **Интерлиньяж:** 1.15 для заголовков, 1.45 для текста.
- **Радиусы:** 999 чипы · 16 кнопка · 20 карточка · 28 лист · 12 иконка.
- **Линии:** 1 px hairline, только `rgba(255,255,255,.12)`.
- **Цель нажатия:** 44 × 44 минимум, 48 для круглых кнопок в шапке.
- **Безопасные зоны:** сверху 59 (чёлка), снизу 34 (полоса).
- **Анимации:** 160 мс вход, 220 мс лист, пульс рамки сканирования.
  При `prefers-reduced-motion: reduce` анимаций нет.

## Иконки

24 × 24, штрих 1.75, `currentColor`, скругления линий. Двенадцать штук:
Хит, Выбор шефа, Острое, Вегетарианское, Халяль, Новинка, Звук включён, Звук выключен,
Поделиться, Минус, Плюс, Закрыть.

## Решения макета, обязательные к соблюдению

1. **Читаемость.** Ни одного полупрозрачного текста. Плашки лежат на затемнении 0.82 с размытием 20 px
   и волосяной линией сверху. Белый текст всегда 100 процентов, вторичный `#E5DED2`.
2. **Геометрия.** Экран делится на три полосы: шапка 0 до 120 px, свободный центр для блюда,
   рабочая зона снизу от 480 px. Всё частое в нижней трети, цель не меньше 44 × 44.
3. **Дорого.** Один тёплый акцент, крупная типографика Golos Text 800, широкие поля,
   скругления 20 и 28. Ни одного градиента в интерфейсе.
4. **Кадр.** Камера и видео блюда это защищённые заглушки. Логотип монохромный белый,
   высота 28. Цены шестизначные, поэтому в карточке и чипах для них нужна отдельная колонка.

## Расхождения с текущим кодом, которые нужно закрыть

1. `--ml-accent2` меняет смысл: был светлый оттенок золота, стал контрастный мятный `#46C6A8`
   для промо-бейджа и счётчика. Правится в конфигах ресторанов.
2. Логотип нужен монохромный белый SVG высотой 28. Сейчас цветной PNG.
3. Появляется токен ошибки `--ml-error` и отдельный фон экрана официанта `--ml-waiter-bg`.
4. Подключается шрифт Golos Text вместо системного.
5. Плашка заказа получает отдельную кнопку «Открыть» вместо тапа по всей плашке.
