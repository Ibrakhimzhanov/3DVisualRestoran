# Дизайн: Видео вместо 3D модели в AR

**Дата:** 2026-02-16
**Статус:** Утверждён

## Цель

Заменить 3D модель (Chicken.glb) на видео (video.mp4), которое воспроизводится как плоский экран в AR, привязанный к маркеру.

## Требования

- Видео отображается как плоскость (plane), привязанная к image target
- Автоплей при обнаружении маркера
- Пауза при потере маркера
- Старт без звука (muted), кнопка для включения звука
- Loop воспроизведение

## Подход

A-Frame `<a-plane>` с видеотекстурой внутри MindAR `mindar-image-target`.

## Изменения в index.html

### Удаляем:
- `gesture-handler` компонент (вращение/зум не нужны для видео)
- `appear-animation` компонент
- `<a-asset-item>` для GLB модели
- `<a-gltf-model>` элемент

### Добавляем:
1. **`video-handler` компонент** — управляет play/pause по событиям targetFound/targetLost
2. **`<video>` элемент** в `<a-assets>` — `muted autoplay playsinline loop`
3. **`<a-plane>`** с `material="src: #video-src; shader: flat"` — плоскость с видеотекстурой
4. **Кнопка звука** — HTML overlay, toggle muted/unmuted, показывается только при видимом маркере

### Размеры:
- Plane: ~1.6 x 0.9 (соотношение 16:9) или по фактическим пропорциям видео
- Position: 0 0.5 0 (чуть выше маркера)

### Кнопка звука:
- Фиксированная позиция, правый нижний угол
- Видна только когда маркер найден
- Иконка: 🔇 → 🔊 при нажатии

## Файлы

- **Изменяется:** `index.html`
- **Используется:** `video.mp4` (9.5 МБ)
- **Удалять не нужно:** `Chicken.glb` остаётся в репозитории (можно вернуться)
