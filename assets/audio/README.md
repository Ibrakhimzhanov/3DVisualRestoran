# Аудио MenuLive

Все файлы: MP3, 44.1 кГц, стерео, 192 kbps.
Громкость приведена по EBU R128: музыка -16 LUFS, звуки интерфейса -20 LUFS,
истинный пик у всех не выше -1.5 dBTP.

Сгенерировано через Lumean API: музыка моделью Music v2, звуки через SFX.

## Музыка

| Файл | Длительность | Громкость | Где применяется |
|------|--------------|-----------|-----------------|
| `promo-main.mp3` | 75.000 с | -16 LUFS | Основной рекламный ролик ресторана, горизонтальный формат |
| `promo-short.mp3` | 30.023 с | -16 LUFS | Короткий вертикальный ролик (Reels, Stories, TikTok) |

### promo-main.mp3
Тёплый современный инструментал, 100 BPM, до мажор, без вокала.
Драматургия по таймингу:

- 0:00 - 0:21 мягкое вступление, одиночное фортепиано и щипковая струна, без ударных
- 0:21 - 0:27 переход, вступает аккуратный бит
- 0:27 - 0:40 средняя часть с битом и тёплыми синтезаторами
- 0:40 - 0:49 подъём, ощущение открытия и удивления
- 0:50 - 0:56 переход в финал
- 0:56 - 1:09 полная аранжировка, кульминация
- 1:10 - 1:15 уверенное завершение, финальный аккорд затухает

Трек собран из трёх сгенерированных частей (вступление, середина, финал) с
равномощными кроссфейдами по 2 такта в точках 0:21 и 0:50. Все части
сгенерированы в одном темпе (100 BPM) и одной тональности (до мажор), склейки
выровнены по сетке долей, поэтому стыки не слышны. Причина сборки: API отдаёт
музыку кусками максимум по 30 секунд.

### promo-short.mp3
То же настроение, но собраннее: бит с первой секунды, подъём на 10-й секунде,
плотная середина и резкое уверенное окончание на 29-й секунде.
Сгенерирован целиком, без склеек.

## Звуки интерфейса

Все короткие, сухие, без реверберации, рассчитаны на динамик телефона.
Тихие по громкости (-20 LUFS), чтобы не перебивать музыку и голос.

| Файл | Длительность | Где применяется |
|------|--------------|-----------------|
| `sfx-scan.mp3` | 1.200 с | Успешное распознавание метки, камера поймала меню |
| `sfx-tap.mp3` | 0.480 с | Нажатие на кнопку или элемент интерфейса |
| `sfx-add.mp3` | 0.680 с | Добавление блюда в заказ |
| `sfx-whoosh.mp3` | 0.780 с | Переход между сценами при монтаже ролика |
| `sfx-reveal.mp3` | 1.600 с | Появление 3D-блюда над меню, момент материализации |

### Описание звуков

- `sfx-scan.mp3` - мягкое восходящее двухнотное «дзинь», тёплый тембр, без металла
- `sfx-tap.mp3` - тихий деликатный тап с лёгким низом
- `sfx-add.mp3` - две быстрые ноты вверх по тону, тембр в духе маримбы
- `sfx-whoosh.mp3` - мягкий воздушный переход без свиста, пик примерно в середине
- `sfx-reveal.mp3` - тёплое мерцание с низким подъёмом снизу, ощущение материализации

## Отклонения от исходного задания

- `sfx-tap.mp3` заказан на 0.4 с, но API не принимает значения короче 0.5 с.
  Сгенерировано 0.5 с, фактическая длительность файла 0.480 с.
- `sfx-whoosh.mp3` заказан на 0.9 с. В начале сгенерированного файла было
  102 мс тишины, которая мешала бы синхронизации на монтаже. Тишина срезана,
  итоговая длительность 0.780 с.
- `promo-main.mp3` собран из трёх частей, см. раздел выше.

## Как перекодировать при необходимости

```
ffmpeg -y -i in.mp3 -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 44100 -ac 2 -b:a 192k out.mp3
```

Для звуков интерфейса заменить `I=-16` на `I=-20`.
