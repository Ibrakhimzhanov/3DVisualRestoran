# Звук MenuLive

Сгенерировано через Lumean. Исходники лежат в `raw/`, готовые дорожки в корне папки.

| Файл | Длительность | Где применяется |
|---|---|---|
| `promo-main.mp3` | 75 с | Музыка мастера рекламного ролика 16:9. Собрана из трёх 30-секундных кусков (вступление, середина, финал) со сшивкой по 2 секунды, затухание в конце. Громкость -16 LUFS. |
| `promo-short.mp3` | 30 с | Музыка вертикальной нарезки 9:16. Громкость -16 LUFS. |
| `sfx-scan.mp3` | 1.2 с | Звук успешного распознавания меню: короткое восходящее двухнотное «дзинь». Громкость -20 LUFS. |
| `sfx-tap.mp3` | 1.0 с | Тихий тап по кнопке интерфейса. Громкость -20 LUFS. |

Звуки интерфейса в самом продукте пока не подключены: движок их не воспроизводит.
Они заготовлены для следующего шага и для монтажа роликов.

Модель ограничивает музыкальный заказ 30 секундами, поэтому длинная дорожка собирается
из нескольких кусков через `acrossfade`, а не заказывается одним файлом.
